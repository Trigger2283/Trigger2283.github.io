
In addition to the basic gameplay of the original version, you can also use different animals and, in doing so, use different skills to get through the levels. At the same time, the items in the scene will also help you gain an advantage, if you can obtain them in time.

How to Play?
Keyboard: Use the arrow keys or WASD.
Phone/Tablet: Swipe the screen or tap the directional buttons in the bottom-left corner.
Press Q to use the skill
After the game ends: Click “Play Again”, or press Space / Enter.
