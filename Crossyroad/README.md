# Blocky Crossing

一个使用原生 JavaScript 和 Three.js 制作的低多边形 3D 过马路小游戏。

界面默认为英文，可在开始界面右上角切换 English / 中文；静态界面、技能、道具提示和失败信息都会同步切换。

## 运行

直接双击 `index.html` 即可开始游戏，不需要安装任何工具。

也可以通过本地 HTTP 服务运行。Windows 上执行：

```powershell
.\start-game.ps1
```

如果系统阻止脚本运行，可使用：

```powershell
powershell -ExecutionPolicy Bypass -File .\start-game.ps1
```

或者使用 Python 的本地 HTTP 服务：

```powershell
python -m http.server 8080
```

然后打开 <http://localhost:8080>。用 `Ctrl+C` 停止服务。

Three.js 已保存在项目的 `vendor` 目录中，运行游戏不需要联网，也不需要安装依赖或执行构建。

## 操作

- 键盘：方向键或 WASD
- 手机/平板：滑动屏幕或点击左下角方向键
- 游戏结束后：点击“再来一次”，或按空格/回车

## 已实现

- 低多边形方块美术与正交等距视角
- 无限向前生成的草地与公路
- 镜头后方保留额外地形缓冲，地图回收不会在可见范围内发生
- 不同速度、方向和尺寸的车辆
- 最多连续两排的公路分段，避免大片重复道路
- 铁路、快速列车与专属碰撞反馈
- 水路、漂浮木头、随水移动和落水判定
- 稀有飞行道具：自动飞跃五行并在预留的安全草地落脚
- 稀有护盾道具：抵挡一次车辆、火车或落水危险
- 道具进入玩家视野后限时存在，并在消失前逐渐缩小
- 道具上方显示消失进度条，剩余时间较短时会由绿色变为红色
- 稀有绿色技能充能道具：恢复一次当前角色技能，最多恢复到三次；刷新频率低于飞行与护盾道具
- 三类道具达到各自最小刷新间隔后按概率生成；每连续三行未生成会提高概率，生成后独立重置
- 小鸡专属技能“扑翼跳跃”：按 Q 挥动翅膀，跨过一行地形，每局可使用三次
- 企鹅角色与“踏浪滑行”：水面失足时自动滑过整段连续水路，每局可触发三次
- 奶牛角色与“蛮牛冲撞”：按 Q 前进一行并撞飞汽车、火车或挡路的树，每局可使用三次；木板不会被撞飞
- 开始界面可选择小鸡、企鹅或奶牛，技能面板会随角色切换
- 树木阻挡、跳跃移动、碰撞与失败反馈
- 当前分数与保存在浏览器中的最高分
- 桌面端和触屏端操作
