# 提交准备

- [ ] 将网站代码与 README、prompt_log.md 上传到 GitHub，不含个人配置或测试输出。
- [ ] 部署页面，并从作品集进入“震迹”验证链接有效。
- [ ] 在手机尺寸下检查地图、筛选与列表。
- [ ] 录制 60–90 秒视频；演示使用公共城市，不输入家庭地址。
- [ ] 视频设为持链接可观看，用无痕窗口检查可访问。
- [ ] 在课程原始 Google 表单填写仓库、作品集和视频链接。

建议演示顺序：

1. 0–15 秒：介绍这是 USGS 公共数据地震浏览器，展示更新时间、地图与记录。
2. 15–30 秒：选择过去七天、调整最低震级，展示列表和地图同步变化。
3. 30–50 秒：搜索 Tokyo / 东京，选定参考地点，设距离范围并按距离排序。
4. 50–65 秒：启用地图选点，再点击一处公共地点；点击地震记录查看详情。
5. 65–80 秒：打开隐私说明，解释地图是本地资源，选点不上传；可展示开发者工具中选点不增加请求。
6. 80–90 秒：清除地点，展示 README 与项目文件。

录屏前关闭个人通知、邮件和无关标签页。提交用的视频请通过自己的账户上传；仓库和视频链接需要自行填入课程表单。
