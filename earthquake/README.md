# 震迹 · Earthquake Atlas

一个注重位置隐私的地震浏览网站：USGS 地震列表、可缩放本地地图、时间 / 震级 / 距离筛选，以及本地城市搜索和经纬度选点。无需登录、API 密钥或构建工具，支持手机和电脑。

## API 调用说明（5 句）

1. 网站使用浏览器原生 `fetch`，以 HTTPS GET 请求 USGS 固定接口 `https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/all_week.geojson`，不需要 API 密钥或身份验证。
2. 接口不带用户查询参数，`all_week` 表示最近七天所有震级的全球事件 Feed；应用只展示其中 `properties.type === "earthquake"` 的记录。
3. 返回格式是 GeoJSON `FeatureCollection`，从 `properties.mag/place/time` 读取震级、地点描述和毫秒时间戳，从 `geometry.coordinates` 按经度、纬度、深度（km）的顺序读取位置。
4. 时间、震级与距离筛选在浏览器内执行，距离使用 Haversine 公式计算地表大圆距离，用户坐标不参与任何请求。
5. 页面打开、点击更新和可见页面每五分钟刷新时请求同一个地址；请求省略凭据和 Referer，20 秒超时，失败时保留此前成功下载的数据并明确标注失败。

官方文档：https://earthquake.usgs.gov/earthquakes/feed/v1.0/geojson.php

## 运行

直接双击 `index.html`，用现代 Chrome、Edge 或 Firefox 打开即可；网络需能访问 USGS。地图和城市随项目附带，打开地图不需要地图服务或 CDN。若浏览器策略限制本地文件请求，请用本地 HTTP 服务器运行。

安装 Python 3 后，在本目录执行：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8000`。或安装 Node.js 后运行 `node serve.cjs`，访问同一地址。无需安装 npm 依赖。

## 使用

- 首页右上角的 **语言 / Language** 可切换简体中文和 English，默认中文。界面、地图提示、时间格式及隐私说明同步切换，并保留当前筛选、选点和已展开的记录数量。语言选择只在本页内存中生效，不保存偏好或发起额外网络请求。城市搜索始终支持内置中英文名称；USGS 地震地点描述及来源国家名称保留原文，不使用在线翻译。

- 选择过去 1 小时、24 小时、3 天或 7 天，拖动最低震级滑块；“全部”保留未知及负震级事件。
- 搜索内置城市（244 个，部分支持中文别名），点击搜索结果设置参考地点；也可以点击“在地图上选择地点”再点击地图，或输入合法经纬度。
- 设置参考地点后可选择 100 / 300 / 500 / 1,000 / 3,000 km 距离范围，也可按距离排序。
- 拖动 / 缩放地图，点击震中圆点查看详情；列表中的“地图定位”会跳到对应震中。
- “清除地点”删除本页参考地点及坐标输入；“重置”同时恢复默认筛选。

底图为 Natural Earth 1:110m 数据，仅适合区域探索，并非街道或门牌导航地图；放大不会增加街道细节。如需精确地点，请输入经纬度。城市列表不完整，可使用英文名或地图选点。结果时间按浏览器本地时区显示。数据不是地震预警、完整全球地震目录或风险预测；最新事件可能延迟或修订。

## 隐私设计和边界

- 位置、搜索内容和筛选值只放在页面内存；不使用 GPS、Cookie、localStorage、IndexedDB、Service Worker、遥测或分析 SDK，不提供云同步。
- 地图代码、底图与城市全部随仓库提供，字体来自系统；没有在线瓦片、远程字体或地址解析请求。
- `core.js` 是无网络和存储操作的计算模块。`app.js` 只有一个固定 `fetch` 调用，绝不拼接用户值。
- 页面 CSP 限制脚本来源为本地、限制联网地址为固定 USGS Feed，并禁用表单提交、插件和 base URL；这属于浏览器层防护，不是操作系统级隔离。
- `credentials: 'omit'` 和 `referrerPolicy: 'no-referrer'` 避免附带凭据和来源 URL；`redirect: 'error'` 拒绝重定向。HTTPS 不会对 USGS 隐藏 IP。
- USGS、网站托管商和基础网络设施仍可能接触 IP、访问时间等元数据；本项目承诺应用不主动上传所选位置，不承诺绝对匿名或设备遭入侵后的保护。
- 页面中的外部文档链接仅在主动点击时打开，可能产生正常第三方网站请求。
- 页面刷新会清除位置；从浏览器往返缓存恢复时也清除位置。浏览器扩展、自动填充、系统备份及浏览器实现不在本应用的控制范围内。
- 父级作品集使用自己的外部资源；本隐私说明仅适用于 `earthquake/` 网站，不覆盖作品集其他页面。

## 检查

安装 Node.js 22 或更高版本：

```sh
node tests/core.test.cjs
node tests/browser.test.cjs
```

浏览器测试需要本机 Chrome；默认使用 Windows 标准安装路径，也可通过 `CHROME_PATH` 环境变量指定。测试使用虚构地震数据，并检查筛选、选点、输入校验、错误恢复、移动布局和选点过程中没有新增请求。输出保存在被 Git 排除的 `test-output/` 下。

手动隐私验收：打开开发者工具 Network，刷新页面后修改城市、坐标、距离和地图视野，确认不产生额外网络请求；等待固定周期更新时，仍只有无参数的同一 USGS Feed 请求。断网后已下载数据应仍可筛选；刷新失败应有明显提示。检查 Application 面板没有本应用创建的位置存储项。
